# TypeScript Learning 🚀

Welcome to my **TypeScript Learning Repository**! This repository documents my journey of learning TypeScript, from the basics to advanced concepts through hands-on coding and practice.

### Prerequisites

- [Node.js](https://nodejs.org/)
- Basic knowledge of JavaScript
- A code editor such as VS Code

### Install TypeScript

Install TypeScript globally using npm:

```bash
npm install -g typescript
```

### Compile and Run

Compile a TypeScript file into JavaScript:

```bash
tsc basics.ts
```

Run the generated JavaScript file:

```bash
node basics.js
```

Alternatively, you can use `tsx` to execute TypeScript files directly:

```bash
npx tsx basics.ts
```
